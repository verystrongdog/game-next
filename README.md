# Game Next

game repository is a historical reference, not a source of current decisions.

Start here:

- [docs/workflow/issues.md](docs/workflow/issues.md) defines Issue contracts.
- [docs/design/README.md](docs/design/README.md) explains how accepted design
  fragments enter this repository without copying the old design wholesale.
